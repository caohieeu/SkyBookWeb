SkyBookWeb - Code Flow

Documentation for Specification Pattern, Repository, UnitOfWork, Service & DI flow

1. Tổng quan kiến trúc

▼

Project chia theo kiến trúc Clean Architecture / Onion đơn giản với 4 project chính:

  • Core SkyBookWeb.Core — Entities, Interfaces, Specifications. Không phụ thuộc EF Core.
  • Infra SkyBookWeb.Infrastructure — DbContext, Repositories, UnitOfWork, SpecificationEvaluator.
  • App SkyBookWeb.Application — Services, DTOs, AutoMapper profiles.
  • Web SkyBookWeb — Controllers, Views, DI registration.

Luồng dữ liệu: Controller → Service → Repository/UnitOfWork → SpecificationEvaluator → EF Core → SQL Server.

1

public interface ISpecifications
{
    Expression> Criteria { get; }
    List>> Includes { get; }
    Expression> OrderBy { get; }
    Expression> OrderByDescending { get; }
    int Skip { get; }
    int Take { get; }
    bool IsPagingEnabled { get; }
}
2
Base class cài đặt Core SkyBookWeb.Core/Specifications/BaseSpecification.cs

Cung cấp setter/protected methods để các spec cụ thể build query.

public class BaseSpecification : ISpecifications
{
    public Expression> Criteria { get; private set; }
    public List>> Includes { get; } = new();
    public Expression> OrderBy { get; private set; }
    public Expression> OrderByDescending { get; private set; }
    public int Skip { get; private set; }
    public int Take { get; private set; }
    public bool IsPagingEnabled { get; private set; }

    public BaseSpecification() { }
    public BaseSpecification(Expression> criteria) => Criteria = criteria;

    protected void AddInclude(Expression> include) => Includes.Add(include);
    protected void AddOrderBy(Expression> expr) => OrderBy = expr;
    protected void AddOrderByDescending(Expression> expr) => OrderByDescending = expr;
    protected void ApplyPaging(int take, int skip)
    {
        Take = take; Skip = skip; IsPagingEnabled = true;
    }
}
3
Tạo specification cụ thể Core SkyBookWeb.Core/Specifications/ProductWithSecification.cs

Nhận ProductSpecPrams từ query string, build filter/sort/paging/include.

public class ProductWithSecification : BaseSpecification
{
    public ProductWithSecification([FromQuery] ProductSpecPrams p)
        : base(x =>
            (string.IsNullOrEmpty(p.Search) || x.Title.Contains(p.Search.Trim())) &&
            (!p.CategoryId.HasValue || x.CategoryId == p.CategoryId) &&
            (!p.Id.HasValue || x.Id == p.Id)
        )
    {
        if (p.IncludeCategory) AddInclude(x => x.Category);

        AddOrderBy(x => x.Title);
        ApplyPaging(p.PageSize, p.PageSize * (p.PageIndex - 1));

        if (!string.IsNullOrEmpty(p.Sort))
        {
            switch (p.Sort)
            {
                case "priceAsc":  AddOrderBy(x => x.Price); break;
                case "priceDesc": AddOrderByDescending(x => x.Price); break;
                case "authorAsc": AddOrderBy(x => x.Author); break;
                case "authorDesc":AddOrderByDescending(x => x.Author); break;
                case "isbnAsc":   AddOrderBy(x => x.ISBN); break;
                case "isbnDesc":  AddOrderByDescending(x => x.ISBN); break;
                default:          AddOrderBy(x => x.Title); break;
            }
        }
    }
}
4
Query object Core SkyBookWeb.Core/Specifications/ProductSpecPrams.cs 
public class ProductSpecPrams
{
    private const int MaxPageSize = 50;
    public int PageIndex { get; set; } = 1;
    private int pageSize { get; set; } = 10;
    public int PageSize
    {
        get => pageSize;
        set => pageSize = (value > MaxPageSize) ? MaxPageSize : value;
    }
    public int? CategoryId { get; set; }
    public bool IncludeCategory { get; set; } = false;
    public int? Id { get; set; }
    public string? Sort { get; set; } = string.Empty;
    private string? search;
    public string? Search
    {
        get => search;
        set => search = value?.ToLower() ?? string.Empty;
    }
}
5
Biên dịch spec thành IQueryable Infra SkyBookWeb.Infrastructure/Data/SpecificationEvaluator.cs

Áp dụng lần lượt where → order → paging → includes.

public class SpecificationEvaluator where T : BaseEntity
{
    public static IQueryable GetQuery(IQueryable inputQuery, ISpecifications spec)
    {
        var query = inputQuery.AsQueryable();

        if (spec.Criteria != null) query = query.Where(spec.Criteria);
        if (spec.OrderBy != null) query = query.OrderBy(spec.OrderBy);
        if (spec.OrderByDescending != null) query = query.OrderByDescending(spec.OrderByDescending);
        if (spec.IsPagingEnabled) query = query.Skip(spec.Skip).Take(spec.Take);
        query = spec.Includes.Aggregate(query, (current, include) => current.Include(include));

        return query;
    }
}

Service gọi repository App SkyBookWeb.Application/Implements/ProductService.cs 
public async Task> GetAllWithSpecification(ProductSpecPrams p)
{
    p.IncludeCategory = true;
    var spec = new ProductWithSecification(p);

    var products = await _productRepository.ListAsync(spec);
    return products.Select(x => _mapper.Map(x));
}

public async Task GetProductByIdAsync(int? id, bool includeCategory = false)
{
    if (id == null) return null;

    var spec = new ProductWithSecification(
        new ProductSpecPrams() { Id = id, IncludeCategory = true });
    return await _unitOfWork.Repository().GetEntityWithSpec(spec);
}

5. UnitOfWork & Generic Repository

▼
SkyBookWeb.Infrastructure/Data/UnitOfWork.cs 
public class UnitOfWork : IUnitOfWork
{
    public IGenericRepository Repository() where TEntity : BaseEntity
    {
        var Type = typeof(TEntity).Name;
        if (!_repositories.ContainsKey(Type))
        {
            var typeGeneric = typeof(GenericRepository<>);
            var repositoryInstance = Activator.CreateInstance(
                typeGeneric.MakeGenericType(typeof(TEntity)),
                _dbContext, _loggerFactory
            );
            _repositories.Add(Type, repositoryInstance);
        }
        return (IGenericRepository)_repositories[Type];
    }

    public async Task Complete() => await _dbContext.SaveChangesAsync() > 0;
}

Mỗi entity type chỉ tạo 1 repository instance trong lifetime scope.

6. Tóm tắt flow request

▼
  1. Client gọi URL: /api/product/getall?search=abc&categoryId=1&sort=priceAsc&pageIndex=1&pageSize=10
  2. ASP.NET model bind vào ProductSpecPrams.
  3. ProductController truyền vào _productService.GetAllWithSpecification(specParams).
  4. ProductService tạo ProductWithSecification.
  5. ProductWithSecification build Criteria, Includes, OrderBy, ApplyPaging.
  6. GenericRepository.ListAsync(spec) gọi SpecificationEvaluator.GetQuery(...).
  7. EF Core translate thành SQL và execute.
  8. Trả về Products → mapping sang ProductDto → serialize JSON.

7. Lưu ý quan trọng

▼
Ghi chú logic:
  • ProductService inject cả IGenericRepository lẫn IUnitOfWork — dùng 2 cách khác nhau tùy method.
  • ProductWithSecification luôn gọi AddOrderBy(x => x.Title) trước rồi sau đó switch sort — nếu sort không empty thì order sẽ bị ghi đè cuối cùng.
  • Công thức paging: Skip = PageSize * (PageIndex - 1), Take = PageSize.
  • IncludeCategory mặc định false, nhưng ProductService.GetAllWithSpecification() tự set true.
Điểm cần review:
  • Trong Program.cs gọi app.UseAuthorization() 2 lần — có thể xóa 1 lần.
  • Trong ApplicationServicesExtensions.cs đường dẫn logout bị typo "lougout".
